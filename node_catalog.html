bt_nodes¶

bt_nodes 是开箱插件库，构建产物在 build/lib/libbt_nodes.*。运行时由 NodeFactory::loadPlugin 加载。

类别

节点

说明

Control

Sequence、Fallback、Parallel

组织子树流程。

Decorator

Inverter、Retry、Repeat、ForceSuccess、ForceFailure

包装一个子节点并改写执行策略。

Action

AlwaysSuccess、AlwaysFailure、PrintMessage

示例和调试动作。

Data

SetBlackboard、SetBool、Counter

写黑板数据。

Condition

CompareBlackboard、CheckBool、CooldownCondition

从黑板读取并判断。

Function

FunctionAction、FunctionCondition

调用单例注册表里的 C++ 函数。
